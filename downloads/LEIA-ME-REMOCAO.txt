REMOCAO MANUAL PELO WINDOWS - NAO BAIXAR LIMPADORES

ALERTA: o pacote automatico Remover-Python-e-Bot-Windows.zip foi bloqueado
pelo Microsoft Defender. Ele foi retirado de circulacao. Mantenha o bloqueio;
nao restaure/permita o arquivo e nao desative o antivirus. Testes de simulacao
nao eram uma analise antimalware. Ainda nao ha nome da deteccao confirmado.

1. Feche a janela do INICIAR-PC.cmd.
2. Pressione Win+R, digite ms-settings:appsfeatures e pressione Enter.
3. Procure Python e desinstale as versoes listadas, Python Launcher e Python
   Install Manager. Use somente a opcao Desinstalar do proprio Windows.
4. Apague D:\Armazenamento do Bot. Isso remove o programa, os bancos, backups,
   configuracoes privadas e o ambiente .pc-venv com todas as dependencias
   instaladas para este projeto (discord.py, Pillow, aiohttp, tzdata e outras).
5. Se voce criou um atalho de inicio automatico, abra Win+R > shell:startup
   e apague somente o atalho para INICIAR-PC.cmd.
6. Em Downloads, apague os arquivos e as pastas extraidas deste projeto:
   - Anime-Adventures-PC-2026.10.26.2.zip e sua pasta extraida;
   - Anime-Adventures-PC-2026.10.26.3.zip e sua pasta extraida, se baixou;
   - Correcao-Ask-PC-2026.10.26.3.zip e sua pasta extraida;
   - pastas Anime-Adventures-PC que tenham sobrado da extracao;
   - python-3.12.10-amd64.exe, o instalador que foi indicado;
   - copias repetidas desses arquivos, com (1), (2) etc. no nome.
   O ZIP bloqueado de remocao deve permanecer sob controle do Defender;
   nao restaure o arquivo so para apaga-lo. Nao apague outros downloads.
7. Depois de remover TODAS as instalacoes independentes de Python, podem ser
   apagados os residuos existentes nestas pastas dedicadas, abertas por Win+R:
   %LOCALAPPDATA%\Programs\Python
   %LOCALAPPDATA%\Python
   %APPDATA%\Python
   %LOCALAPPDATA%\pip
   %APPDATA%\pip
   Se alguma pasta nao existir, apenas pule. Nao procurar/apagar Python dentro
   das pastas de outros programas, Windows\Installer ou WindowsApps.

Instalacoes portateis em caminhos personalizados, outras contas e distribuicoes
como Anaconda/Miniconda podem exigir remocao especifica pelas Configuracoes.
Os desinstaladores oficiais cuidam dos registros e atalhos da instalacao.
Nao apague o PATH inteiro nem pastas de sistema para tentar remover residuos.

Se python abrir a Microsoft Store depois, pode ser apenas um alias, sem Python
instalado. Desative python.exe/python3.exe em Configuracoes > Aplicativos >
Configuracoes avancadas > Aliases de execucao, se for o caso.

No Historico de protecao do Defender, consulte o nome da deteccao e a acao
aplicada. Um download bloqueado, sozinho, nao confirma que algo foi executado.
